# Vereint Verweilen

**Official website of the Vereint Verweilen housing project.**

[Vereint Verweilen](https://vereint-verweilen.de/) is a community-oriented project developing an intergenerational place 
to live and work in the rural area around Leipzig, Germany. It brings together private living spaces, shared facilities, 
workshops, co-working and regional initiatives to support sustainable living and stronger local communities.

## About the project

The website introduces the project, its vision, the people behind it and opportunities for collaboration and support.

It presents the concept of combining independent living with shared spaces, practical skills and regional engagement — creating 
a place where different generations can live, work and contribute together.

## Technical overview

The website is built with plain HTML, CSS and JavaScript, without a frontend framework or build system.

- **HTML** for structure and content
- **CSS** for layouts, typography and visual design
- **JavaScript** for interactive functionality

This lightweight approach keeps the codebase straightforward, easy to maintain and free from unnecessary dependencies.

## Development

No build step or package installation is required.

Clone the repository and open `index.html` in a browser, or serve the project locally using any static web server.

```bash
git clone https://github.com/LifterSam/vereint-verweilen.git
cd vereint-verweilen
```

The website can be maintained directly in its HTML, CSS and JavaScript files.
